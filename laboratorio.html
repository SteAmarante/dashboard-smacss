Dashboard SMACSS

      
Grupos de 4 a 5 pessoas, 30 minutos, nas salas simultâneas. O starter kit é o projeto-final da aula passada (pasta dashboard-smacss), com o HTML e o JavaScript já prontos. Vocês só escrevem SCSS.

Como abrir o projeto

        
    
          
  1. StackBlitz: em stackblitz.com, crie um projeto Node.js em branco, arraste os arquivos da pasta e rode npm install e npm run dev.
    2. 
          
  2. VS Code local: na pasta do kit, rode npm install e npm run dev e abra http://localhost:5173.
    3. 
          
  3. Sem Node: use a extensão Live Sass Compiler, como na aula passada.
    4. 
        

      

      

        
Regras e entrega

        
    
          
  • BEM continua nos módulos. Modificador -- é variação do HTML; estado is- é ligado pelo JavaScript.
    • 
          
  • Dentro dos módulos, só var(--dsc-*).
    • 
          
  • Estado de módulo fica no arquivo do módulo: .sidebar.is-aberta.
    • 
          
  • Se o botão Menu aparecer no desktop, confira a ordem do module/_index.scss: btn vem antes de header.
    • 
          
  • Entrega: link ou .zip, mais dois prints (tema escuro no desktop e sidebar aberta no mobile), no chat geral.
